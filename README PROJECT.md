Minha Saúde Feminina

> Acompanhe sua saúde, registre sintomas e tenha informações confiáveis sempre à mão.

---

Sobre o Aplicativo

O **Minha Saúde Feminina** é um aplicativo mobile desenvolvido para auxiliar mulheres no acompanhamento da saúde feminina de forma simples, acessível e confiável. Por meio de recursos como calendário menstrual, lembretes de consultas e exames, e conteúdos educativos, o app oferece uma experiência completa de cuidado com a saúde.

O projeto foi desenvolvido como trabalho acadêmico, aplicando conceitos de design de interface (UI/UX), prototipação e desenvolvimento mobile multiplataforma.

---

Objetivo

- Facilitar o acompanhamento do ciclo menstrual
- Oferecer conteúdos educativos sobre saúde feminina
- Permitir o registro e monitoramento de sintomas
- Enviar lembretes de consultas e exames preventivos
- Promover o bem-estar físico e mental da usuária

---

Telas do Aplicativo

| Tela | Descrição |
|------|-----------|
| **Splash / Boas-vindas** | Tela inicial com logo, botões de Entrar e Criar Conta |
| **Criar Conta** | Cadastro com Nome, Idade, Email, Senha e Fase da vida |
| **Início (Home)** | Acesso rápido às funcionalidades e Dica do dia |
| **Calendário** | Visualização e acompanhamento do ciclo menstrual |
| **Conteúdos** | Categorias educativas com vídeos e áudios |
| **Lembretes** | Gerenciamento de lembretes de consultas e exames |
| **Perfil** | Gerenciamento das informações da usuária |

Como Executar o Projeto

Pré-requisitos

- [Node.js](https://nodejs.org/) instalado (versão 18 ou superior)
- [Expo CLI](https://docs.expo.dev/get-started/installation/) instalado
- Aplicativo **Expo Go** no celular ([Android](https://play.google.com/store/apps/details?id=host.exp.exponent) | [iOS](https://apps.apple.com/app/expo-go/id982107779))

Instalação

```bash
Clone o repositório
git clone https://github.com/seu-usuario/minha-saude-feminina.git

Acesse a pasta do projeto
cd minha-saude-feminina

Instale as dependências
npm install

Inicie o projeto
npx expo start
```

Executando no celular

1. Abra o aplicativo **Expo Go** no seu celular
2. Escaneie o QR Code gerado no terminal
3. O app será carregado automaticamente
